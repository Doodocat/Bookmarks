Adi's Dot-Bookmarks

Note: Everything listed here consists of websites, tools, and resources I personally use.

Web Development & Frameworks

  • Astro — Fast, content-focused web framework.
  • Vite — Next-generation frontend build tool and dev server.
  • MDN Web Docs — Official reference for HTML, CSS, JavaScript, and Web APIs.
  • Tailwind CSS — Utility-first CSS framework documentation.
  • Can I use... — Browser support tables for modern web features.

Languages & Build Environments

  • Python — Official Python language home and documentation.
  • uv — Extremely fast Python package installer and virtualenv manager.
  • Bun — Fast all-in-one JavaScript/TypeScript runtime and package manager.
  • MSYS2 — Software distribution and build environment for GCC/MinGW on Windows.
  • cppreference — Comprehensive C and C++ standard library documentation.

Terminal & Browser Setup

  • VS Code — Primary code editor and ecosystem.
  • Waterfox — Customizable, privacy-focused browser.

Digital Libraries & Tools

  • Anna's Archive — Open-source search engine for books and papers.
  • Open-Slum — Uptime dashboard tracking availability of digital library mirrors.
  • WeLib — Digital library platform for accessing open books and articles.

Knowledge & Notes

  • Obsidian — Markdown-based local personal knowledge base.
  • Logseq — Local-first, privacy-focused outliner tool.
  • NotebookLM — AI-powered research assistant for documents.

Strategy, Cinema & Media

  • Sudoku.com — Classic logic-based number placement puzzle game.
  • Letterboxd — Social network for tracking, rating, and logging films.
